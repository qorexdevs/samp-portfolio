# SAMP / CRMP demo systems

Демо-мод на Pawn для open.mp и SA-MP 0.3.7: автосалон, ГИБДД со штрафами, поворотники и аварийка, спидометр с топливом, админ-система.

- `src/` исходники модулей и `demo.pwn`
- `src/bugfixes.md` типичные ошибки в модах и их исправления
- `portfolio/`, `portfolio-bugs/` карточки для портфолио

Сборка: исходники перевести в CP1251 и собрать `pawncc demo.pwn` с include от SA-MP или open.mp.
